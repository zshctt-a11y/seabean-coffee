# seabean-coffee
SEABEAN 海豆咖啡 — 品牌官网（海洋意象咖啡馆：首页 / 菜单 / 品牌 / 到访）

## 线上地址
GitHub Pages：`https://zshctt-a11y.github.io/seabean-coffee/`
（在 Settings → Pages 中选择 Deploy from branch → main /(root) 即可启用）

## 还差一步：上传 4 张门店照片
网站代码已全部就绪。四张图片需要手动上传到 `assets/` 目录：

1. 打开 https://github.com/zshctt-a11y/seabean-coffee/upload/main/assets
2. 把 `assets` 文件夹里的 4 个 jpg 拖进页面（或点 choose your files 多选）：
   - hero_sea_coffee.jpg（首页主视觉）
   - shop_exterior.jpg（门面）
   - shop_interior.jpg（吧台）
   - shop_seating.jpg（客座区）
   图片文件见随附的 `seabean-site-images.zip`
3. 点 Commit changes。

上传前网站也能正常打开：图片位置会显示品牌渐变占位，上传后立即恢复照片。

## 页面结构
- index.html — 首页（主视觉 / 空间概念 / 招牌菜单 / 空间影像）
- menu.html — 完整菜单
- about.html — 品牌故事
- visit.html — 到访信息（滨海路 23 号 · 怀德大厦旁）
- assets/ — 样式、脚本与图片
